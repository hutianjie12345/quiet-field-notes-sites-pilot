06Policies

Privacy policy.

This candidate policy distinguishes Learning Engine integration data from the information website and its hosting.

Candidate revision: 13 October 2026 · Public release pending review

Review status

This is a proposed update for the website pilot. The existing policy at learning.quietfieldnote.com remains the current public policy until an approved replacement is released. This page does not verify the integration’s current OAuth configuration.

Scope

This policy describes the personal Learning Engine n8n integration and the Quiet Field Notes information website. It does not describe a public signup, paid service, or public access to private learning records.

Google Drive access

The legacy integration documentation states that the workflow reads metadata and contents of request files in its configured Drive folder, writes results back to those files, and updates filenames. Requests and results may contain learning notes, questions, source excerpts, topics, timestamps, and retrieved information.

The existing policy states that the configured OAuth permission allows broader Drive access than the workflow’s folder filter. That filter is an application behavior, not a restriction on the credential’s permissions. The website pilot has not verified the current consent-screen settings or scope list, and does not assert that permissions have been narrowed.

Processing and storage

The existing integration policy describes request and result files remaining in the authorized Google Drive account, processing by the owner’s local n8n instance, and storage of results and learning records by a local learning service. It also describes local model generation of candidates for review and possible information in workflow execution records and backups.

Those descriptions are retained pending verification of the current integration. They must not be interpreted as a verified inventory of every present-day service or store.

If the owner uses a connected chat application to submit or read files, that application also processes the selected content under its own settings and policies. This information website does not collect Google authorization tokens or submit learning requests.

Purpose and sharing

The integration is intended to use information for the owner’s requested learning functions. The existing integration policy states that it does not sell learning data, use it for advertising, or use it to train generalized AI models. This statement describes the operator’s stated use of integration data; it is not a claim about all third-party providers’ practices.

Data passes through the services the owner chooses to use. The use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Retention and control

The owner can revoke Google access and stop the workflow. Revocation stops future authorized access but does not erase existing Drive files, local records, execution history, or backups. Those copies require separate deletion in their respective systems. This pilot has not verified an automatic deletion deadline or a complete deletion workflow.

Website hosting and traffic measurement

The existing public website is hosted by GitHub Pages. The candidate website is being evaluated on ChatGPT Sites. The website contains no custom analytics SDK, advertising, submission form, or public account registration.

Depending on the Site’s sharing settings, access may require platform-managed ChatGPT sign-in. When that sign-in is used, basic profile information such as name and email address may be shared for authentication. These static pages do not implement visitor-profile storage or personalized learning features.

ChatGPT Sites automatically records traffic and exposes visitor and page-view statistics. Hosting and platform measurement therefore remain relevant even without analytics scripts in this website’s source. Provider processing is governed by the applicable provider terms and policies; this page does not assert specific analytics identifiers, cookies, or retention periods that have not been verified.

See the official Sites documentation, OpenAI privacy policy, and GitHub privacy statement.
