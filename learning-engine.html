03Learning Engine

Keep the source.
Keep the judgment.

A personal learning project for organizing source-linked material and retrieving reviewed records, with human review at the boundary of authoritative memory.

Experimental · personal use

Not a public SaaS service.

PurposeConceptual architectureEvidence & limitsData & privacy

What the project is for

Learning Engine addresses a practical problem: how to make learning notes retrievable without losing their sources, review state, or limitations. The project is intended for its owner’s personal use.

The existing public integration is named Learning Engine n8n. Its documentation describes requests passing through a designated Google Drive folder and a locally operated n8n workflow. That description is retained as documentation of the integration, not as a fresh claim that the entire bridge is currently operating.

Observed · bounded

Read-only memory retrieval

A retrieval call returned records with source references and explicit validity information during this website’s preparation. This demonstrates that bounded retrieval call; it does not establish full ingestion coverage or workflow completion.

Not established here

End-to-end operation

The current Google Drive bridge, automated processing, deletion behavior, broad coverage, and continuous availability have not been independently accepted by this website pilot.

What the project does not establish

  • A retrieved or generated answer is not a substitute for checking its source.
  • The presence of a paper or note does not establish mastery.
  • A candidate or derived index is not automatically an authoritative record.
  • A successful component check does not establish the success of an entire learning workflow.

Data and access

This website provides project information. It does not accept learning requests, connect visitors to the private knowledge base, or collect Google authorization tokens.

Information about the legacy integration’s processing, retention, and revocation is described in the privacy policy. The policy distinguishes project data processing from website hosting and traffic measurement.
